## Selected work

- [crisis-ews-tft](https://github.com/sarpvulas/crisis-ews-tft): my MSc dissertation. A leak-free test of deep-learning early warning for S&P 500 drawdown crises. An auxiliary drawdown head helped (+0.034 macro PR-AUC, p = 0.031). Regime awareness did not.
- [AgentBasedProject](https://github.com/sarpvulas/AgentBasedProject): an agent-based market with a limit order book. The simulated returns have fat tails. The README lists which market facts the model reproduces and which it does not.
- [Lecturely](https://github.com/sarpvulas/lecturely-showcase): an AI exam prep app for the SAT and AP exams, which I founded. The repo shows the product and the architecture. The code is private.
- [Sideman](https://github.com/sarpvulas/Sideman): a jazz piano teacher. It reads a lead sheet with Gemini Vision and checks your chords through the microphone. Early-stage prototype.
